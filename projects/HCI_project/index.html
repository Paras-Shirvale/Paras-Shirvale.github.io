Spark can’t find its files

The page loaded, but its stylesheets and scripts did not. That means index.html is being opened on its own, without the folders that belong next to it.

Almost always, this is one of these

  1. Opened from inside the zip. Double-clicking a file in a zip preview copies only that one file to a temporary folder, leaving everything else behind.
  2. Only index.html was extracted, rather than the whole spark-ai folder.
  3. The server is running in the wrong folder, one level above or below the one holding index.html.

To fix it

  1. Right-click the zip and choose Extract All — not just a preview or a double-click.
  2. Open the extracted spark-ai folder. You should see index.html, css, js and fonts sitting side by side.
  3. Run start.bat (Windows) or bash start.sh (Mac/Linux) from inside that folder.

Starting it that way also matters for the microphone: browsers only allow it on http://localhost, which the start script sets up. Opening the file directly turns off reading aloud and dictation even when the styling is fine.

Spark can’t find its files

This page loaded, but the folders that go with it (css, js, fonts) did not. That is why it looks like a plain document.

Almost always this means:

  • The zip was opened without extracting it first. On Windows, double-clicking a zip shows its contents like a folder, but opening a file from in there copies out only that one file. Right-click the zip → Extract All, then open the extracted folder.
  • Or index.html was moved away from its sibling folders. All of them have to stay together.

The folder you open index.html from must also contain the css, js and fonts folders.
